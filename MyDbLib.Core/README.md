# MyDbLib

A lightweight, provider-agnostic ADO.NET database library for .NET.

## Features
- SQL Server, MySQL, PostgreSQL ready architecture
- Clean separation: Api / Core / Providers
- Async-first design
- No ORM, no EF dependency
- Safe parameterized queries
- Extensible provider model
